# AQUA Self-Pruning Network

A from-scratch neural-network implementation for the Tredence AQUA technical challenge.

## Scope and restrictions

The core engine, autodiff, optimizer, pruning algorithm, and training loop will be implemented by us using Python and NumPy. We will not use PyTorch, TensorFlow, JAX, Keras, Hugging Face, or any autodiff, pruning, or neural-network library. Scikit-learn, if used later, will be restricted to dataset loading; the initial dataset is generated with NumPy.

## Setup

Python 3.10+ is required.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## Current status

Phase 0: project skeleton and deterministic synthetic dataset generator.

Generate and inspect a small batch:

```bash
python -m train.data
```

Run the tests:

```bash
python -m pytest
```

## Planned milestones

1. `engine/`: Tensor, reverse-mode autodiff, broadcasting-aware gradient accumulation, numerical gradient checks.
2. `nn/`: composable layers, MLP, Adam optimizer, training loop.
3. `prune/`: importance scores, gradual pruning, mask/optimizer-state correctness, sparse-aware inference.
4. `experiments/`: reproducible sparsity/accuracy/cost sweeps and magnitude-pruning baseline.
5. `results/`, `README.md`, and `DESIGN.md`: raw metrics, plots, design rationale, and reproducible commands.

All reported metrics will be generated by committed scripts; no results will be fabricated or hard-coded.
